# Security Policy

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting on the repository's **Security** tab so the
report, follow-up discussion, and any coordinated disclosure remain private.

Include the affected version, impact, reproduction steps or a proof of concept,
and any known mitigations. You can expect an acknowledgement within three
business days and a status update within seven business days.
